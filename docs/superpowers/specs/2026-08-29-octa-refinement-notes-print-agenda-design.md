# OCTA Refinement — Notes, Screenshot, Agenda and Navigation

## Scope
Preserve the approved visual system and existing routes while applying only the requested interaction and layout refinements.

## Requirements
- Notes must persist as records with title, subject and message.
- Notes opened from navigation or a meeting must appear as a floating draggable card so the user never has to leave a meeting to write.
- Screenshot must be removed from the sidebar and exposed as a persistent global corner control on app pages and meetings.
- Calculator dragging must remain smooth and bounded to the viewport.
- Remove the decorative play glyph from the sidebar recordings label.
- Remove Plans and Prices from the sidebar and add it to the main top navigation.
- Keep Anotar in the sidebar, but make it open the floating note card instead of navigating away.
- Keep only the bottom sidebar collapse/expand control.
- Fix lower home card clipping and remove the duplicated astronaut background treatment in the lower card.
- Agenda create modal must collect subject, date, time and selected participants using avatar miniatures.
- Existing OCTA SKILLS, filters, profile editing, meetings, Supabase/LiveKit routes and approved colors/layout stay intact.
