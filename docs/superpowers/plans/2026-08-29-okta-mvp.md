# OKTA MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deployable vertical-first videoconference MVP with demo mode plus production-ready Supabase/LiveKit adapters.

**Architecture:** Next.js App Router + TypeScript with feature folders and a shared design system. The UI works immediately with local demo state; when environment variables are present, Supabase and LiveKit adapters become active without restructuring the app.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Lucide, Supabase JS, LiveKit client/server SDKs, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-08-29-okta-mvp-design.md`

## Global Constraints

- Vertical 9:16 video is the default meeting layout on desktop and mobile.
- MVP must remain usable without external credentials via demo mode.
- Supabase RLS and LiveKit secrets are never exposed client-side.
- AI, billing, facial/emotion analysis and cloud recording are architecture-ready but not implemented in v1.
- UI is dark, premium, glassy, minimal and responsive.
